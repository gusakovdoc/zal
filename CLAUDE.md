# Зал

Приложение для тренировок: один файл `index.html`, ванильный JS без сборки,
хостится на GitHub Pages. Устанавливается как PWA, работает офлайн.

Файл описывает **договорённости и решения**, а не содержимое кода. Списков
функций тут намеренно нет — они устаревают быстрее, чем правятся. Если
написанное расходится с кодом, прав код, а файл надо поправить.

---

## Два репозитория

| Что | Где | Кто пишет |
|---|---|---|
| Код приложения | `F:\Zal` → `gusakovdoc/zal` (публичный) | Claude |
| Данные и разбор | `F:\zal-data` → `gusakovdoc/zal-data` (приватный) | приложение и Claude |

В `zal-data` два файла. `data.json` приложение выгружает само после каждой
тренировки через GitHub API. `advice.json` пишет Claude — приложение его
только читает и показывает.

**Токен GitHub хранится в браузере и намеренно не входит в `dump()`** —
иначе он уехал бы в сам репозиторий вместе с данными.

## Еженедельный цикл

Пользователь пишет «проанализируй». Дальше:

1. `git -C F:\zal-data pull` и прочитать `data.json`;
2. прогнать цифры **через функции самого приложения**, а не считать заново —
   иначе разбор разойдётся с тем, что человек видит на экране;
3. переписать `advice.json`, обязательно сменив поле `at` — по нему
   приложение понимает, что разбор новый;
4. запушить.

В `advice.json`: `note` — короткий вывод, `general` — карточки на главной,
`ex` — рекомендации по упражнениям, они показываются прямо в карточках во
время тренировки. Ключи `ex` — id упражнений из `EX`.

## Как проверять правки

**Гонять в браузере, а не читать код.** Здесь много вещей, которые в коде не
видны: обрывы звука, перехват жестов, поведение таймеров.

Порядок: поднять `python -m http.server` на папке `F:\Zal`, подсунуть
реальные данные из `zal-data`, выполнить сценарий скриптом, проверить
консоль и отсутствие горизонтальной прокрутки на ширине 375.

**Касания и мышь ведут себя по-разному.** Перетаскивание один раз прошло
проверку мышью и не работало на телефоне. Для жестов диспетчерить
`PointerEvent` с `pointerType:'touch'`.

**После проверки чистить состояние** — тесты пишут в `localStorage` того же
origin, что и превью.

## Решения, к которым пришли не сразу

**Расход калорий берётся по факту, а не по формуле.** Съеденное минус то,
что осело в набор веса. Миффлин и MET-таблицы ошибались на 800 ккал.
Формула осталась запасным вариантом, пока нет данных.

**Рекорд — среднее по рабочим подходам, и его надо превзойти.** По лучшему
подходу было выгодно вложиться в первый и слить остальные. Повтор прежнего
результата рекордом не считается: правило одно на всё приложение — `isRecord`.
Той же меркой (`exScore`) считаются застой и индекс силы. Индекс берёт ПОСЛЕДНЮЮ
тренировку по упражнению, а не лучшую: по лучшей он не мог опуститься после
перерыва или слабой недели.

**Разгрузка — отметка недели, а не другие цифры в логе.** `S.deload[неделя]`
режет подходы вдвое и подставляет повторы на треть ниже, а тренировки этой
недели лежат в логе как обычные, но пропускаются всем, что считает прогресс:
«прошлый раз», рекорды, графики, застой, индекс силы. Иначе урезанные
подходы легли бы провалом на график, а следующая неделя подставила бы
половинчатые цифры. Флаг на неделе, а не в записи — чтобы его можно было
снять или поставить задним числом. Мобильность и локоть не режутся.

**План недели замораживается.** Прошлые недели считаются по снимку плана,
текущая — по живому. Иначе правка плана переоценивала задним числом уже
прожитые недели.

**Звуков ровно три**, у каждого один смысл: пауза пошла, подход начался,
упражнение закрыто. Плюс короткие тики на последние секунды паузы.
Сигналы ставятся в очередь звукового движка заранее — иначе они не звучат
при погасшем экране. Уже зазвучавший сигнал обрывать нельзя.

**Перетаскивание упражнений — отдельный режим.** Пока оно жило поверх
обычного экрана, шапку приходилось отнимать у прокрутки.

**`navigator.onLine` не показывает наличие интернета**, только наличие
интерфейса. Связь проверяется настоящим запросом.

## Конвенции

- Комментарии по-русски и объясняют **почему**, а не что.
- Стиль ES5: `var`, `function`, без стрелок и классов — файл открывается
  как есть, без сборки.
- Правки данных упражнений удобнее делать скриптом на Python с проверкой
  «не найдено», чем руками: строки длинные и похожие.
- Коммиты по-русски, в теле — причина правки и чем проверено.
- **Пушить только после проверки в браузере.**
- Версию кэша в `sw.js` поднимать, когда меняется набор файлов.

## Чего в приложении нет намеренно

Сборки, зависимостей, фреймворка, сервера. Всё состояние — один объект `S`
в `localStorage`, выгрузка в облако его же и повторяет.
